# hr-microservices

Reprodução pessoal do curso [Microsserviços Java com Spring Boot e Spring Cloud](https://github.com/acenelio/ms-course), ministrado por Nelio Alves (DevSuperior). Progresso rastreado via GitHub Issues e Projects.

## Progresso e board

O progresso é rastreado por issue, uma por aula (35 no total), agrupadas em 4 milestones por fase. O board é público, com workflow integrado: criar uma branch pra uma issue move ela pra "Em Andamento"; abrir um PR referenciando a issue move pra "Resumo"; mergear o PR, com o resumo da aula presente, fecha a issue e move pra "Concluído".

Board: https://github.com/users/CamposCodes/projects/4

## Créditos
Todo o crédito pelo conteúdo original do curso pertence ao instrutor Nelio Alves. Este repositório é uma reprodução para fins de estudo e portfólio.

## English

Personal reproduction of the course [Java Microservices with Spring Boot and Spring Cloud](https://github.com/acenelio/ms-course), taught by Nelio Alves (DevSuperior). Progress tracked via GitHub Issues and Projects.

### Progress and board

Progress is tracked per issue, one per lesson (35 total), grouped into 4 milestones by phase. The board is public, with an integrated workflow: creating a branch for an issue moves it to "Em Andamento" (In Progress); opening a PR referencing the issue moves it to "Resumo" (Summary); merging the PR, with the lesson's summary file present, closes the issue and moves it to "Concluído" (Done).

Board: https://github.com/users/CamposCodes/projects/4
