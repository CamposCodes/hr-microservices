# 1.6 Feign

`RestTemplate` substituído por `WorkerFeignClient`, uma interface anotada com `@FeignClient` que declara o endpoint do hr-worker (`GET /workers/{id}`), sem escrever a chamada HTTP na mão. `PaymentService` agora chama `workerFeignClient.findById(workerId)` em vez de montar URL e Map de variáveis.

Também existe diferença no tratamento de erro entre os dois: RestTemplate lança `org.springframework.web.client.HttpClientErrorException` quando o servidor remoto responde com erro, enquanto o Feign usa hierarquia própria, `feign.FeignException`.

---

#### English

`RestTemplate` replaced by `WorkerFeignClient`, an interface annotated with `@FeignClient` declaring the hr-worker endpoint (`GET /workers/{id}`), no manual HTTP call. `PaymentService` now calls `workerFeignClient.findById(workerId)` instead of building a URL and a variables Map.

There is also a difference in error handling between the two: RestTemplate throws `org.springframework.web.client.HttpClientErrorException` when the remote server returns an error, while Feign uses its own hierarchy, `feign.FeignException`.
