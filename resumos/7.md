# 1.7 Ribbon load balancing

Dependência `spring-cloud-starter-netflix-ribbon` adicionada ao hr-payroll, habilitando load balancing no lado do cliente entre múltiplas instâncias do hr-worker. `@FeignClient` do `WorkerFeignClient` perdeu a URL fixa (`http://localhost:8001`), agora resolve o endereço via Ribbon, usando a lista de servidores configurada em `hr-worker.ribbon.listOfServers` (`localhost:8001,localhost:8002`). No hr-worker, log adicionado em `WorkerController.findById` mostrando a porta que atendeu a requisição, pra confirmar visualmente o load balancing entre as instâncias.

Vantagem: com mais de uma instância do hr-worker registrada, as requisições se distribuem entre elas em vez de sempre irem pra uma só. Isso evita sobrecarregar uma única instância e mantém o sistema respondendo mesmo se uma delas cair.

---

#### English

`spring-cloud-starter-netflix-ribbon` dependency added to hr-payroll, enabling client-side load balancing across multiple hr-worker instances. `WorkerFeignClient`'s `@FeignClient` lost the fixed URL (`http://localhost:8001`), now resolving the address via Ribbon, using the server list configured in `hr-worker.ribbon.listOfServers` (`localhost:8001,localhost:8002`). In hr-worker, a log was added in `WorkerController.findById` showing which port handled the request, to visually confirm load balancing across instances.

Advantage: with more than one hr-worker instance registered, requests get distributed across them instead of always going to a single one. This avoids overloading a single instance and keeps the system responding even if one of them goes down.
