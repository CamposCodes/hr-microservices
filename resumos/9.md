# 2.2 Configurar hr-eureka-server

hr-eureka-server configurado como Discovery Server de verdade. Pontos de configuração:

- `@EnableEurekaServer` adicionada na classe principal, ativando o servidor Eureka
- Dependência `jaxb-runtime` adicionada (necessária pro Eureka rodar em Java 11+, já que o JAXB saiu do JDK)
- `server.port=8761` (porta padrão do Eureka) e `spring.application.name=hr-eureka-server`
- `eureka.client.register-with-eureka=false` e `eureka.client.fetch-registry=false`: força essa instância a atuar só como servidor, sem tentar se registrar nela mesma como cliente

---

#### English

hr-eureka-server configured as a real Discovery Server. Configuration points:

- `@EnableEurekaServer` added to the main class, activating the Eureka server
- `jaxb-runtime` dependency added (needed for Eureka to run on Java 11+, since JAXB was removed from the JDK)
- `server.port=8761` (Eureka's default port) and `spring.application.name=hr-eureka-server`
- `eureka.client.register-with-eureka=false` and `eureka.client.fetch-registry=false`: forces this instance to act only as a server, without trying to register itself as a client
