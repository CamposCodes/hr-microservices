# 1.5 RestTemplate

`PaymentService` passou a chamar o hr-worker de verdade via `RestTemplate` (bean configurado em `AppConfig`), em vez de dados mockados. Criado `Worker` como classe de transporte pra receber a resposta do hr-worker. Adicionado tratamento de erro (`ResourceNotFoundException`, `StandardError`, `ResourceExceptionHandler`) pra quando o hr-worker responde 404.

---

#### English

`PaymentService` now calls hr-worker for real via `RestTemplate` (bean configured in `AppConfig`), instead of mocked data. Created `Worker` as a transport class to receive the hr-worker response. Added error handling (`ResourceNotFoundException`, `StandardError`, `ResourceExceptionHandler`) for when hr-worker responds with 404.
