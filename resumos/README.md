# Resumos

Um arquivo por issue, nomeado pelo numero da issue: `1.md`, `2.md`, `35.md`, e assim por diante. O check `check-resumo` exige esse arquivo no PR antes de liberar o merge.

---

#### English

One file per issue, named by the issue number: `1.md`, `2.md`, `35.md`, and so on. The `check-resumo` check requires this file in the PR before allowing the merge.
